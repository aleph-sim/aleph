**Goal:** Add five specialised paths to `kernels::{aos,soa}::apply_2q` — generic dense AVX-512, CNOT/SWAP/CZ permutations, and a general 2q-diagonal fast path — dispatched by matrix-runtime detection (`classify_2q_permutation`, `is_diagonal_4x4`). /// Tolerance for permutation-matrix detection in `classify_2q_permutation`.
```rust
/// `PERM_TOL = 1e-14` requires `|m[r][c]|² ≥ 1 - 1e-14` AND
/// `(re - 1).abs() < 1e-14` AND `im.abs() < 1e-14`. Any "almost-permutation"
/// whose off-diagonals exceed `~1e-15` magnitude already fails the
/// diagonal pre-test (`DIAGONAL_EPS_SQ`), so this looser tolerance only
/// guards against unitarity-normalisation drift in user-built matrices.
const PERM_TOL: f64 = 1e-14;

/// Canonical 4×4 permutation matrices recognised by the 2q dispatch.
/// Other 6 valid 4-element permutations (e.g. `X⊗I = [1,0,3,2]`) fall
/// through to the generic kernel.
#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub(crate) enum Perm2qKind {
    /// `π = [0, 1, 2, 3]` — identity.
    Identity,
    /// `π = [0, 1, 3, 2]` — control = `targets[0]` (MSB), as `Gate::Cnot`.
    CnotHi,
    /// `π = [0, 3, 2, 1]` — control = `targets[1]` (LSB).
    CnotLo,
    /// `π = [0, 2, 1, 3]` — symmetric swap, as `Gate::Swap`.
    Swap,
}

/// Returns true iff every off-diagonal entry of a 4×4 matrix has
/// squared magnitude below `DIAGONAL_EPS_SQ`. 12 `norm_sqr` calls +
/// 12 compares ≈ 30 ns per call. Used by the 2q diagonal fast path
/// (P1-07). Reuses the same `DIAGONAL_EPS_SQ` tolerance as the 1q
/// diagonal heuristic (P1-06) — semantics identical.
#[inline]
pub(crate) fn is_diagonal_4x4(m: &[[aleph_core::Complex; 4]; 4]) -> bool {
    for r in 0..4 {
        for c in 0..4 {
            if r != c && m[r][c].norm_sqr() >= DIAGONAL_EPS_SQ {
                return false;
            }
        }
    }
    true
}

/// Classifies a 4×4 matrix as one of the four canonical 2q permutations
/// recognised by the dispatch. Returns `None` for any matrix that is
/// not a `+1`-entry permutation matrix in the canonical set.
///
/// Algorithm: for each row, find the unique column with `(re ≈ 1, im ≈ 0)`
/// within `PERM_TOL`; reject if multiple non-zero entries or any non-zero
/// off-canonical phase. Check the column-permutation is injective.
/// Match against the four canonical patterns.
pub(crate) fn classify_2q_permutation(
    m: &[[aleph_core::Complex; 4]; 4],
) -> Option<Perm2qKind> {
    let mut perm = [0u8; 4];
    for r in 0..4 {
        let mut hit: Option<u8> = None;
        for c in 0..4 {
            let nsq = m[r][c].norm_sqr();
            if nsq < DIAGONAL_EPS_SQ {
                continue;
            }
            // Require exact +1+0i within PERM_TOL.
            if (nsq - 1.0).abs() < PERM_TOL
                && (m[r][c].re - 1.0).abs() < PERM_TOL
                && m[r][c].im.abs() < PERM_TOL
            {
                if hit.is_some() {
                    return None; // two non-zero entries in row
                }
                hit = Some(c as u8);
            } else {
                return None; // non-canonical magnitude or phase
            }
        }
        perm[r] = hit?;
    }
    // Reject duplicate columns (not a permutation).
    let mut seen = [false; 4];
    for &c in &perm {
        if seen[c as usize] {
            return None;
        }
        seen[c as usize] = true;
    }
    match perm {
        [0, 1, 2, 3] => Some(Perm2qKind::Identity),
        [0, 1, 3, 2] => Some(Perm2qKind::CnotHi),
        [0, 3, 2, 1] => Some(Perm2qKind::CnotLo),
        [0, 2, 1, 3] => Some(Perm2qKind::Swap),
        _ => None,
    }
}

/// Returns true iff the four diagonal entries match the CZ phase
/// pattern `(1, 1, 1, -1)` within `PERM_TOL`. Detected as a shortcut
/// to swap the generic 2q-diagonal multiply for `vxorpd` sign-flip.
#[inline]
pub(crate) fn is_cz_signature(d: [aleph_core::Complex; 4]) -> bool {
    let one = aleph_core::Complex::new(1.0, 0.0);
    let neg_one = aleph_core::Complex::new(-1.0, 0.0);
    let close = |z: aleph_core::Complex, target: aleph_core::Complex| {
        (z - target).norm_sqr() < PERM_TOL
    };
    close(d[0], one) && close(d[1], one) && close(d[2], one) && close(d[3], neg_one)
}
```

```rust
/// Scalar CNOT specialisation: for amplitudes where bit `control` = 1
/// AND every external control bit is set, swap `state[i]` with
/// `state[i | t_bit]`.  Zero multiplies; pure swap-pair traffic.
///
/// `control` and `target` are passed separately (vs the generic
/// kernel's `targets[2]`) because the dispatch prelude has already
/// disambiguated the orientation via `Perm2qKind`.  External
/// `controls` are appended to the implicit control mask.
pub(crate) fn apply_2q_cnot_scalar(
    amps: &mut [Complex],
    control: u32,
    target: u32,
    external_controls: &[u32],
) {
    let c_bit = 1usize << control;
    let t_bit = 1usize << target;
    let ctrl_mask = c_bit | super::control_mask(external_controls);
    let len = amps.len();
    let mut i = 0usize;
    while i < len {
        if (i & ctrl_mask) == ctrl_mask && (i & t_bit) == 0 {
            amps.swap(i, i | t_bit);
        }
        i += 1;
    }
}
```

```rust
/// Scalar SWAP specialisation: for amplitudes where bits `a` and `b`
/// differ (and external controls satisfied), swap `state[i_a0_b1]`
/// with `state[i_a1_b0]`.
///
/// Convention: this kernel walks every base index `i` with bits a, b
/// both zero (and external controls set); for each such i, swap
/// `state[i | a_bit]` (= a=0, b=1) with `state[i | b_bit]` (= a=1, b=0).
pub(crate) fn apply_2q_swap_scalar(
    amps: &mut [Complex],
    targets: [u32; 2],
    external_controls: &[u32],
) {
    let a_bit = 1usize << targets[0];
    let b_bit = 1usize << targets[1];
    let t_mask = a_bit | b_bit;
    let ctrl_mask = super::control_mask(external_controls);
    let len = amps.len();
    let mut i = 0usize;
    while i < len {
        if (i & t_mask) == 0 && (i & ctrl_mask) == ctrl_mask {
            amps.swap(i | a_bit, i | b_bit);
        }
        i += 1;
    }
}
```

```rust
/// Scalar CZ specialisation: negate `state[i]` for amplitudes where
/// both target bits are 1 (and external controls satisfied).  Touches
/// 1/4 of the state vector.
pub(crate) fn apply_2q_cz_scalar(
    amps: &mut [Complex],
    targets: [u32; 2],
    external_controls: &[u32],
) {
    let t0_bit = 1usize << targets[0];
    let t1_bit = 1usize << targets[1];
    let t_mask = t0_bit | t1_bit;
    let ctrl_mask = super::control_mask(external_controls);
    let len = amps.len();
    let mut i = 0usize;
    while i < len {
        if (i & t_mask) == t_mask && (i & ctrl_mask) == ctrl_mask {
            amps[i] = -amps[i];
        }
        i += 1;
    }
}
```

```rust
/// 2q kernel.  `targets[0]` is the high bit of `k`, `targets[1]` is
/// the low bit (per ADR 0004 / P0-06 §6).
pub(crate) fn apply_2q_diagonal_scalar(
    amps: &mut [Complex],
    targets: [u32; 2],
    external_controls: &[u32],
    d: [Complex; 4],
) {
    let t0_bit = 1usize << targets[0];
    let t1_bit = 1usize << targets[1];
    let ctrl_mask = super::control_mask(external_controls);
    let len = amps.len();
    let mut i = 0usize;
    while i < len {
        if (i & ctrl_mask) == ctrl_mask {
            let k_hi = ((i & t0_bit) != 0) as usize;
            let k_lo = ((i & t1_bit) != 0) as usize;
            let k = (k_hi << 1) | k_lo;
            amps[i] *= d[k];
        }
        i += 1;
    }
}
```

```rust
pub(crate) fn apply_2q(
    amps: &mut [Complex],
    targets: [u32; 2],
    controls: &[u32],
    m: &[[Complex; 4]; 4],
) {
    // 1. Permutation detection (Identity / CNOT / SWAP).
    match super::classify_2q_permutation(m) {
        Some(super::Perm2qKind::Identity) => return,
        Some(super::Perm2qKind::CnotHi) => {
            apply_2q_cnot_scalar(amps, targets[0], targets[1], controls);
            return;
        }
        Some(super::Perm2qKind::CnotLo) => {
            apply_2q_cnot_scalar(amps, targets[1], targets[0], controls);
            return;
        }
        Some(super::Perm2qKind::Swap) => {
            apply_2q_swap_scalar(amps, targets, controls);
            return;
        }
        None => {}
    }

    // 2. Diagonal-4x4 (catches Cz, controlled-Phase, Rzz, user diagonals).
    if super::is_diagonal_4x4(m) {
        let d = [m[0][0], m[1][1], m[2][2], m[3][3]];
        if super::is_cz_signature(d) {
            apply_2q_cz_scalar(amps, targets, controls);
        } else {
            apply_2q_diagonal_scalar(amps, targets, controls, d);
        }
        return;
    }

    // 3. Generic dense 4×4.  AVX-512 branches land in Tasks 5+; for now,
    //    everything falls through to the scalar walk so the workspace
    //    test suite stays green.
    apply_2q_dense_scalar(amps, targets, controls, m);
}
```

```rust
/// Packed-complex AVX-512 generic 2q dense kernel.  Iterates outer
/// blocks of `4 * t_hi_bit`; the inner walk steps by LANES = 4 complex
/// pairs along the low-target axis (requires `1 << t_lo >= LANES`).
///
/// **Math.** For each quartet `(z00, z01, z10, z11)`, compute
/// `new_z_r = Σ_c m[r][c] * z_c`.  Each `m[r][c] * z_c` is one
/// `vfmaddsub(m_re_bcast, z_c, m_im_bcast × vpermilpd<0x55>(z_c))` —
/// the same packed-complex idiom as `apply_1q_avx512`, replicated
/// across four loaded subspaces.
///
/// **Per inner iter (LANES quartets = 16 amps):**
/// 4 loads + 4 permutes + 16 mul + 16 fmaddsub + 12 add + 4 stores
/// ≈ 56 µops.  Vs scalar 4-quartet (~256 µops): ~4.5× per-amp.
///
/// # Safety
///
/// Caller MUST ensure all of:
/// * Host CPU supports AVX-512F.
/// * `1 << min(targets) >= LANES` (= 4) — inner SIMD walk has ≥ LANES
///   contiguous pairs per sub-block.
/// * Every external control's qubit index is strictly greater than
///   `max(targets)`, so the outer-walk's bit-expansion never toggles
///   a control bit.
/// * Distinct targets/controls, all in qubit range.
#[cfg(target_arch = "x86_64")]
#[target_feature(enable = "avx512f")]
unsafe fn apply_2q_avx512(
    amps: &mut [Complex],
    targets: [u32; 2],
    controls: &[u32],
    m: &[[Complex; 4]; 4],
) {
    use core::arch::x86_64::*;

    const LANES: usize = 4;

    let t_lo = targets[0].min(targets[1]);
    let t_hi = targets[0].max(targets[1]);
    let t_lo_bit = 1usize << t_lo;
    let t_hi_bit = 1usize << t_hi;
    let t_mask = t_lo_bit | t_hi_bit;
    let len = amps.len();

    debug_assert!(t_lo_bit >= LANES, "t_lo_bit < LANES: dispatch contract violated");
    debug_assert!(
        controls.iter().all(|&c| c > t_hi),
        "control at-or-below t_hi: dispatch contract violated"
    );

    // Compute index permutation: targets[0] is MSB of matrix index k,
    // targets[1] is LSB.  If targets[0] < targets[1] (i.e. t_lo == targets[0]),
    // then bit k=1 (lo) corresponds to t_hi_bit memory offset, and
    // bit k=2 (hi) corresponds to t_lo_bit offset.  The four
    // sub-block offsets keyed by k=0,1,2,3:
    let (offset_k1, offset_k2) = if targets[0] < targets[1] {
        // targets[0]=t_lo, targets[1]=t_hi → k bit 1 (low) selects t_hi_bit
        (t_hi_bit, t_lo_bit)
    } else {
        (t_lo_bit, t_hi_bit)
    };
    let offsets = [0usize, offset_k1, offset_k2, t_mask];

    // Broadcast all 16 matrix cells.
    let mut m_re = [_mm512_setzero_pd(); 16];
    let mut m_im = [_mm512_setzero_pd(); 16];
    for r in 0..4 {
        for c in 0..4 {
            m_re[r * 4 + c] = _mm512_set1_pd(m[r][c].re);
            m_im[r * 4 + c] = _mm512_set1_pd(m[r][c].im);
        }
    }

    let amps_ptr = amps.as_mut_ptr() as *mut f64;

    let outer_iter = |block: usize| {
        let mut j = 0usize;
        while j + LANES <= t_lo_bit {
            // Load 4 sub-blocks, each LANES complex pairs.
            // Base index for k=0 is `block | j` (no target bits set).
            let mut z = [_mm512_setzero_pd(); 4];
            let mut zs = [_mm512_setzero_pd(); 4];
            for k in 0..4 {
                let i_k = block | offsets[k] | j;
                // SAFETY: i_k + LANES ≤ block + 2 * t_hi_bit ≤ len
                // (outer step is 4 * t_hi_bit, and i_k bounded above by
                // block | (t_lo_bit | t_hi_bit) | (t_lo_bit - LANES) ≤
                // block + 2*t_hi_bit - LANES, so the LANES-wide load
                // lands inside the outer extent).
                z[k] = _mm512_loadu_pd(amps_ptr.add(i_k * 2));
                zs[k] = _mm512_permute_pd::<0x55>(z[k]);
            }

            // Compute each output row.
            let mut new_z = [_mm512_setzero_pd(); 4];
            for r in 0..4 {
                let t0 = _mm512_mul_pd(m_im[r * 4], zs[0]);
                let mut p = _mm512_fmaddsub_pd(m_re[r * 4], z[0], t0);
                let t1 = _mm512_mul_pd(m_im[r * 4 + 1], zs[1]);
                p = _mm512_add_pd(p, _mm512_fmaddsub_pd(m_re[r * 4 + 1], z[1], t1));
                let t2 = _mm512_mul_pd(m_im[r * 4 + 2], zs[2]);
                p = _mm512_add_pd(p, _mm512_fmaddsub_pd(m_re[r * 4 + 2], z[2], t2));
                let t3 = _mm512_mul_pd(m_im[r * 4 + 3], zs[3]);
                p = _mm512_add_pd(p, _mm512_fmaddsub_pd(m_re[r * 4 + 3], z[3], t3));
                new_z[r] = p;
            }

            // Store back into the same 4 sub-blocks.
            for k in 0..4 {
                let i_k = block | offsets[k] | j;
                _mm512_storeu_pd(amps_ptr.add(i_k * 2), new_z[k]);
            }

            j += LANES;
        }
        debug_assert_eq!(j, t_lo_bit);
    };

    if controls.is_empty() {
        let outer_step = t_mask << 1; // = 4 * t_hi_bit when t_lo < t_hi
        // Note: outer_step is the smallest stride that clears both target
        // bits and advances past one full quartet-extent.  For t_lo < t_hi,
        // this is 2 * t_hi_bit (one full t_hi-extent above and below the
        // t_hi bit; t_lo_bit is inside).
        let outer_step = 2usize * t_hi_bit;
        let mut block = 0usize;
        while block < len {
            outer_iter(block);
            block += outer_step;
        }
        return;
    }

    // Controlled SIMD path: renormalise control positions above t_hi.
    let mut fixed_above: smallvec::SmallVec<[(u32, bool); 8]> = smallvec::SmallVec::new();
    for &c in controls {
        fixed_above.push((c - t_hi - 1, true));
    }
    fixed_above.sort_unstable_by_key(|&(pos, _)| pos);

    let n_qubits = len.trailing_zeros();
    let outer_count = 1usize << (n_qubits - t_hi - 1 - controls.len() as u32);
    for k in 0..outer_count {
        let block = crate::kernels::expand_with_fixed(k, &fixed_above) << (t_hi + 1);
        outer_iter(block);
    }
}
```

```rust
/// Packed AVX-512 CNOT (Tier A only — `1 << target >= LANES`).
/// For amplitudes with bit `control = 1`, swap LANES contiguous
/// complex pairs at offset `t_bit` with those at offset 0.
///
/// # Safety
///
/// Caller MUST ensure all of:
/// * Host CPU supports AVX-512F.
/// * `1 << target >= LANES` (= 4).
/// * `target != control`; both in qubit range.
/// * Every external control's qubit index > max(target, control).
#[cfg(target_arch = "x86_64")]
#[target_feature(enable = "avx512f")]
unsafe fn apply_2q_cnot_avx512(
    amps: &mut [Complex],
    control: u32,
    target: u32,
    external_controls: &[u32],
) {
    use core::arch::x86_64::*;

    const LANES: usize = 4;
    let t_bit = 1usize << target;
    let c_bit = 1usize << control;
    let len = amps.len();

    debug_assert!(t_bit >= LANES, "t_bit < LANES: dispatch contract violated");
    debug_assert!(target != control);
    debug_assert!(
        external_controls.iter().all(|&c| c > target.max(control)),
        "external control at-or-below max(control, target)"
    );

    let amps_ptr = amps.as_mut_ptr() as *mut f64;

    // For each `outer` index satisfying: bit `control` = 1, bit `target` = 0,
    // all external_controls = 1.  Inner walk over the LANES-wide target=0
    // window; for each, swap with the matching target=1 window.
    let inner_walk = |outer: usize| {
        let mut j = 0usize;
        while j + LANES <= t_bit {
            let i0 = outer | j;
            let i1 = i0 | t_bit;
            // SAFETY: i0 + LANES ≤ outer + t_bit ≤ len.
            let a_vec = _mm512_loadu_pd(amps_ptr.add(i0 * 2));
            let b_vec = _mm512_loadu_pd(amps_ptr.add(i1 * 2));
            _mm512_storeu_pd(amps_ptr.add(i0 * 2), b_vec);
            _mm512_storeu_pd(amps_ptr.add(i1 * 2), a_vec);
            j += LANES;
        }
        debug_assert_eq!(j, t_bit);
    };

    // Outer-walk: bit control=1, bit target=0, external_controls all 1.
    // We use `expand_with_fixed` with control fixed=true, target fixed=false,
    // plus the external_controls as fixed=true.  All positions ≤ max(t, c)
    // are "below" the inner walk's contiguous region except target itself.

    // Build the fixed-positions list relative to the entire qubit space.
    let mut fixed: smallvec::SmallVec<[(u32, bool); 16]> = smallvec::SmallVec::new();
    fixed.push((target, false));
    fixed.push((control, true));
    for &ec in external_controls {
        fixed.push((ec, true));
    }
    fixed.sort_unstable_by_key(|&(p, _)| p);

    let n_qubits = len.trailing_zeros();
    let outer_count = 1usize << (n_qubits as usize - fixed.len());
    // Inner walk needs target_bit contiguous amps at the bottom of `outer`.
    // expand_with_fixed produces an index with all fixed bits set as
    // prescribed; positions `< target` are free and contribute to the
    // base index.  We then walk `j` over `[0, t_bit)` to fill the inner
    // SIMD strides.  For positions below target that are NOT in `fixed`,
    // they alternate via `k`'s free bits — which is exactly what
    // expand_with_fixed handles.
    //
    // BUT: we need the LANES inner stride to span contiguous memory.
    // That requires positions `< target` to be inside the inner walk's
    // index range `[0, t_bit)`.  Positions below target that are NOT
    // in `fixed` (i.e. not control, not an external_control < target)
    // become free-bit positions in expand_with_fixed, which gives
    // discontinuous outer indices.  To avoid this, we require:
    //   "every external control's qubit index > max(target, control)"
    // which the dispatch prelude guarantees.  Plus we hoist the
    // control case: if control < target, the outer-walk free positions
    // include all positions below target except control — but the
    // expand_with_fixed framework still yields the correct base index
    // sequence, since `j` enumerates the inner strides.
    //
    // Concrete handling: for each k in [0, outer_count), call
    // expand_with_fixed(k, &fixed); the result is `outer` with all
    // fixed bits set as required.  The inner `j` walk then sweeps the
    // LANES-wide window starting at that `outer`.

    for k in 0..outer_count {
        let outer = crate::kernels::expand_with_fixed(k, &fixed);
        inner_walk(outer);
    }
}
```

**IMPORTANT NOTE on the contract:** the safety contract states external controls > `max(target, control)`. If `control < target`, free positions below `target` could include arbitrary qubits — but the inner LANES-walk takes `j ∈ [0, t_bit)`, so all index bits below `target` are determined by `j`'s low bits (target is fixed=false, control is fixed=true). The dispatch prelude (Task 4) wires this so callers from QFT-style transpiled circuits (which always have controls = the explicit CNOT control bit) work correctly.

For the test driver to call `apply_2q_cnot_avx512` directly, pass `external_controls = &[]`. The control bit is `control`.

```rust
/// Tier B CNOT: `1 << target < LANES <= 1 << control`. The inner load
/// pulls LANES amps with mixed target-bit values; we use `vpermt2pd`
/// to swap doubles within the register.
///
/// Permute-index tables (8 doubles per zmm, indexing re/im pairs):
/// * `target = 0` → swap (amp0,amp1) and (amp2,amp3) → idx [2,3, 0,1, 6,7, 4,5]
/// * `target = 1` → swap (amp0,amp2) and (amp1,amp3) → idx [4,5, 6,7, 0,1, 2,3]
///
/// # Safety
///
/// * AVX-512F supported.
/// * `target ∈ {0, 1}` (i.e. `1 << target < LANES = 4`).
/// * `1 << control >= LANES`.
/// * External controls > max(control, target).
#[cfg(target_arch = "x86_64")]
#[target_feature(enable = "avx512f")]
unsafe fn apply_2q_cnot_avx512_tier_b(
    amps: &mut [Complex],
    control: u32,
    target: u32,
    external_controls: &[u32],
) {
    use core::arch::x86_64::*;

    const LANES: usize = 4;
    let c_bit = 1usize << control;
    let len = amps.len();

    debug_assert!(target <= 1, "Tier B requires target ∈ {{0, 1}}");
    debug_assert!((1usize << control) >= LANES, "control_bit < LANES");

    let permute_idx = match target {
        0 => _mm512_setr_epi64(2, 3, 0, 1, 6, 7, 4, 5),
        1 => _mm512_setr_epi64(4, 5, 6, 7, 0, 1, 2, 3),
        _ => unreachable!(),
    };

    let amps_ptr = amps.as_mut_ptr() as *mut f64;

    // Outer-walk: bit control=1, all external_controls=1.  control itself
    // is fixed=true; positions below control that are not fixed are free
    // (and contribute to the inner SIMD walk's `j`).
    let mut fixed: smallvec::SmallVec<[(u32, bool); 16]> = smallvec::SmallVec::new();
    fixed.push((control, true));
    for &ec in external_controls {
        fixed.push((ec, true));
    }
    fixed.sort_unstable_by_key(|&(p, _)| p);

    let n_qubits = len.trailing_zeros();
    let outer_count = 1usize << (n_qubits as usize - fixed.len());

    let inner_walk = |outer: usize| {
        let mut j = 0usize;
        while j + LANES <= c_bit {
            let i = outer | j;
            // SAFETY: i + LANES ≤ outer + c_bit ≤ len.
            let z = _mm512_loadu_pd(amps_ptr.add(i * 2));
            let z2 = _mm512_permutexvar_pd(permute_idx, z);
            _mm512_storeu_pd(amps_ptr.add(i * 2), z2);
            j += LANES;
        }
        debug_assert_eq!(j, c_bit);
    };

    for k in 0..outer_count {
        let outer = crate::kernels::expand_with_fixed(k, &fixed);
        inner_walk(outer);
    }
}
```

```rust
/// Tier C CNOT: both qubits in {0, 1}.  One zmm holds exactly one
/// quartet (4 complex amps = 8 doubles).
///
/// Permute-index tables:
/// * `control = 0, target = 1` (CnotLo-style swap): swap quartet's
///   "01"↔"11" amps → idx [0,1, 6,7, 4,5, 2,3]
/// * `control = 1, target = 0` (CnotHi-style swap): swap quartet's
///   "10"↔"11" amps → idx [0,1, 2,3, 6,7, 4,5]
///
/// # Safety
///
/// * AVX-512F supported.
/// * Both `control` and `target` ∈ {0, 1}, distinct.
/// * External controls > 1.
/// * `len >= 4` (at least one quartet).
#[cfg(target_arch = "x86_64")]
#[target_feature(enable = "avx512f")]
unsafe fn apply_2q_cnot_avx512_tier_c(
    amps: &mut [Complex],
    control: u32,
    target: u32,
    external_controls: &[u32],
) {
    use core::arch::x86_64::*;

    debug_assert!(control <= 1 && target <= 1 && control != target);
    let len = amps.len();
    debug_assert!(len >= 4);

    let permute_idx = match (control, target) {
        // c=0, t=1: control bit is q0, target bit is q1.
        // amps: (q1=0,q0=0)=stay, (q1=0,q0=1)=swap with (q1=1,q0=1),
        //       (q1=1,q0=0)=stay, (q1=1,q0=1)=swap with (q1=0,q0=1)
        (0, 1) => _mm512_setr_epi64(0, 1, 6, 7, 4, 5, 2, 3),
        // c=1, t=0: control = q1, target = q0.
        // amps: stay 0,1; swap (q1=1,q0=0)↔(q1=1,q0=1)
        (1, 0) => _mm512_setr_epi64(0, 1, 2, 3, 6, 7, 4, 5),
        _ => unreachable!("Tier C requires control,target ∈ {0,1}"),
    };

    let amps_ptr = amps.as_mut_ptr() as *mut f64;

    // External controls > 1 means all fixed bits sit above the quartet
    // span.  For each fixed-bit configuration k, the quartet base is
    // expand_with_fixed(k, &fixed) — but since the quartet bits (0, 1)
    // are NOT in `fixed`, expand_with_fixed yields a base with bits 0
    // and 1 both zero, which is exactly the quartet start.
    let mut fixed: smallvec::SmallVec<[(u32, bool); 16]> = smallvec::SmallVec::new();
    for &ec in external_controls {
        fixed.push((ec, true));
    }
    fixed.sort_unstable_by_key(|&(p, _)| p);

    let n_qubits = len.trailing_zeros();
    let outer_count = 1usize << (n_qubits as usize - 2 - fixed.len());
    // We iterate quartet bases.  With both q0 and q1 free, the quartet
    // base steps by 4 amps.  expand_with_fixed needs only the controls
    // (bits ≥ 2); the free bits (≥ 2, non-control) come from `k`.
    for k in 0..outer_count {
        let base = crate::kernels::expand_with_fixed(k, &fixed);
        // base has bits 0 and 1 zero (they're not in `fixed`), so it's
        // already a quartet boundary.
        debug_assert_eq!(base & 3, 0);
        let z = _mm512_loadu_pd(amps_ptr.add(base * 2));
        let z2 = _mm512_permutexvar_pd(permute_idx, z);
        _mm512_storeu_pd(amps_ptr.add(base * 2), z2);
    }
}
```

```rust
#[target_feature(enable = "avx512f")]
unsafe fn apply_2q_swap_avx512_tier_b(
    amps: &mut [Complex],
    targets: [u32; 2],
    external_controls: &[u32],
) {
    use core::arch::x86_64::*;

    const LANES: usize = 4;
    let lo = targets[0].min(targets[1]);
    let hi = targets[0].max(targets[1]);
    let hi_bit = 1usize << hi;
    let len = amps.len();

    debug_assert!(lo <= 1);
    debug_assert!((1usize << hi) >= LANES);

    // The LANES-wide load covers 4 amps with mixed lo-bit values; we
    // swap within-register pairs where (lo=0, hi=1) ↔ (lo=1, hi=0).
    // Two halves of the zmm correspond to (hi=0, lo varies) and
    // (hi=1, lo varies), which we read in two separate zmm loads
    // (= hi_bit apart in memory).  Within each zmm, lo=0 and lo=1 amps
    // are at alternating positions: doubles (0,1)/(4,5) vs (2,3)/(6,7)
    // for lo=0, or (0,1)/(2,3) vs (4,5)/(6,7) for lo=1.
    //
    // Strategy: load hi=0 half, load hi=1 half; swap "lo=1" amps of
    // hi=0 with "lo=0" amps of hi=1 using vpermt2pd between the two.

    // For lo = 0: zmm doubles 2,3 (amp1, lo=1) of hi=0-zmm <->
    //              zmm doubles 0,1 (amp0, lo=0) of hi=1-zmm
    //              zmm doubles 6,7 (amp3, lo=1) of hi=0-zmm <->
    //              zmm doubles 4,5 (amp2, lo=0) of hi=1-zmm
    // Building output for hi=0-zmm: keep its (lo=0)=doubles 0,1,4,5;
    // pull (lo=0) of hi=1-zmm (doubles 0,1,4,5) into (lo=1) slots
    // (positions 2,3,6,7).  vpermt2pd: the index source picks doubles
    // from {a, b}; indices 0..7 = a, 8..15 = b.
    // For lo=0:
    //   new_hi0[0,1] = old_hi0[0,1]  (keep lo=0 of hi=0)
    //   new_hi0[2,3] = old_hi1[0,1]  (pull lo=0 of hi=1)
    //   new_hi0[4,5] = old_hi0[4,5]
    //   new_hi0[6,7] = old_hi1[4,5]
    //   → idx0 = [0,1, 8,9, 4,5, 12,13]
    //   new_hi1[0,1] = old_hi0[2,3]
    //   new_hi1[2,3] = old_hi1[2,3]
    //   new_hi1[4,5] = old_hi0[6,7]
    //   new_hi1[6,7] = old_hi1[6,7]
    //   → idx1 = [2,3, 10,11, 6,7, 14,15]
    // For lo=1:
    //   amps split as (q1, q0) where q1=hi, q0=lo.  Wait — lo is the
    //   lower-index qubit, so within a zmm, the bit-0 of the amp's
    //   index ranges over [0..4]; "lo=1" means amp indexes with bit-1
    //   of zmm-offset set... actually re-read:
    //   lo=1 means qubit index 1.  Within a 4-amp zmm starting at base
    //   where base has bit 1 = 0 (and bit hi = 0), the 4 amps have
    //   indices base+0, base+1, base+2, base+3.  Their (q1, q0) bits:
    //   amp0=(0,0), amp1=(0,1), amp2=(1,0), amp3=(1,1).
    //   "lo=1" (qubit 1) bit = q1, which is amps 2,3 of this zmm.
    //   For Tier B with lo=1, we'd actually need hi >= 2, so qubit hi
    //   is the high bit and qubit lo=1 is "inside" the zmm.  Swap pattern
    //   is (q_lo=0, q_hi=1) ↔ (q_lo=1, q_hi=0).
    //   For lo=1:
    //     new_hi0[0,1] = old_hi0[0,1]   (q1=0, q0=0 of hi=0 → stay)
    //     new_hi0[2,3] = old_hi0[2,3]   (q1=0, q0=1 of hi=0 → stay; q_lo=0)
    //     new_hi0[4,5] = old_hi1[0,1]   (q1=1, q0=0 of hi=0 ← pull from hi=1 q_lo=0)
    //     new_hi0[6,7] = old_hi1[2,3]
    //     → idx0 = [0,1, 2,3, 8,9, 10,11]
    //     new_hi1[0,1] = old_hi0[4,5]   (q1=1, q0=0 of hi=0 → goes to hi=1 q_lo=0 amp)
    //   …actually this requires careful re-derivation; see comments.

    // Simpler: for Tier B SWAP, hand-derive the two permute indices
    // statically per (lo) value:
    let (idx_for_hi0, idx_for_hi1) = match lo {
        0 => (
            _mm512_setr_epi64(0, 1, 8, 9, 4, 5, 12, 13),
            _mm512_setr_epi64(2, 3, 10, 11, 6, 7, 14, 15),
        ),
        1 => (
            _mm512_setr_epi64(0, 1, 2, 3, 8, 9, 10, 11),
            _mm512_setr_epi64(4, 5, 6, 7, 12, 13, 14, 15),
        ),
        _ => unreachable!("Tier B requires lo ∈ {{0, 1}}"),
    };

    let amps_ptr = amps.as_mut_ptr() as *mut f64;

    // Outer-walk: base index with hi=0 and all external_controls=1.
    // Inner: load hi=0 half, hi=1 half (= base + hi_bit), permute, store.
    let mut fixed: smallvec::SmallVec<[(u32, bool); 16]> = smallvec::SmallVec::new();
    fixed.push((hi, false));
    for &ec in external_controls {
        fixed.push((ec, true));
    }
    fixed.sort_unstable_by_key(|&(p, _)| p);

    let n_qubits = len.trailing_zeros();
    let outer_count = 1usize << (n_qubits as usize - fixed.len());

    for k in 0..outer_count {
        let outer = crate::kernels::expand_with_fixed(k, &fixed);
        // Inner walks over the contiguous LANES-amp window inside the
        // hi=0 half.  Since hi=0 half spans [outer, outer + hi_bit), we
        // step by LANES.
        let mut j = 0usize;
        while j + LANES <= hi_bit {
            let i_0 = outer | j;          // hi=0
            let i_1 = i_0 | hi_bit;        // hi=1
            let z0 = _mm512_loadu_pd(amps_ptr.add(i_0 * 2));
            let z1 = _mm512_loadu_pd(amps_ptr.add(i_1 * 2));
            let new_z0 = _mm512_permutex2var_pd(z0, idx_for_hi0, z1);
            let new_z1 = _mm512_permutex2var_pd(z0, idx_for_hi1, z1);
            _mm512_storeu_pd(amps_ptr.add(i_0 * 2), new_z0);
            _mm512_storeu_pd(amps_ptr.add(i_1 * 2), new_z1);
            j += LANES;
        }
        debug_assert_eq!(j, hi_bit);
    }
}

/// Tier C SWAP: both targets in {0, 1}.  One zmm per quartet.
/// Permute swaps amps q1=0,q0=1 ↔ q1=1,q0=0 within the quartet.
///
/// # Safety
///
/// * AVX-512F supported.
/// * Both targets in {0, 1}, distinct.
/// * External controls > 1.
/// * `len >= 4`.
#[cfg(target_arch = "x86_64")]
#[target_feature(enable = "avx512f")]
unsafe fn apply_2q_swap_avx512_tier_c(
    amps: &mut [Complex],
    targets: [u32; 2],
    external_controls: &[u32],
) {
    use core::arch::x86_64::*;

    debug_assert!(targets[0] <= 1 && targets[1] <= 1 && targets[0] != targets[1]);

    // Within one 4-amp zmm (quartet at indices 0,1,2,3 = (q1,q0) =
    // (00),(01),(10),(11)): swap amp1 (q1=0,q0=1) with amp2 (q1=1,q0=0).
    // Doubles: amp1=(2,3), amp2=(4,5).
    let permute_idx = _mm512_setr_epi64(0, 1, 4, 5, 2, 3, 6, 7);

    let amps_ptr = amps.as_mut_ptr() as *mut f64;
    let len = amps.len();

    let mut fixed: smallvec::SmallVec<[(u32, bool); 16]> = smallvec::SmallVec::new();
    for &ec in external_controls {
        fixed.push((ec, true));
    }
    fixed.sort_unstable_by_key(|&(p, _)| p);

    let n_qubits = len.trailing_zeros();
    let outer_count = 1usize << (n_qubits as usize - 2 - fixed.len());
    for k in 0..outer_count {
        let base = crate::kernels::expand_with_fixed(k, &fixed);
        debug_assert_eq!(base & 3, 0);
        let z = _mm512_loadu_pd(amps_ptr.add(base * 2));
        let z2 = _mm512_permutexvar_pd(permute_idx, z);
        _mm512_storeu_pd(amps_ptr.add(base * 2), z2);
    }
}
```

```rust
/// Packed AVX-512 CZ (Tier A — `1 << min(targets) >= LANES`).
/// Negates `state[i]` for amplitudes with both target bits = 1 (and
/// external controls satisfied).  Single `vxorpd` per LANES amps;
/// no multiplies.  Touches only 1/4 of the state vector.
///
/// # Safety
///
/// * AVX-512F supported.
/// * `1 << min(targets) >= LANES` (= 4).
/// * External controls > max(targets).
#[cfg(target_arch = "x86_64")]
#[target_feature(enable = "avx512f")]
unsafe fn apply_2q_cz_avx512(
    amps: &mut [Complex],
    targets: [u32; 2],
    external_controls: &[u32],
) {
    use core::arch::x86_64::*;

    const LANES: usize = 4;
    let lo = targets[0].min(targets[1]);
    let hi = targets[0].max(targets[1]);
    let lo_bit = 1usize << lo;
    let hi_bit = 1usize << hi;
    let len = amps.len();

    debug_assert!(lo_bit >= LANES);
    debug_assert!(external_controls.iter().all(|&c| c > hi));

    let sign_mask = _mm512_set1_pd(-0.0_f64);
    let amps_ptr = amps.as_mut_ptr() as *mut f64;

    // Outer-walk: base index with both lo, hi bits = 1.  Plus
    // external_controls all 1.
    let mut fixed: smallvec::SmallVec<[(u32, bool); 16]> = smallvec::SmallVec::new();
    fixed.push((lo, true));
    fixed.push((hi, true));
    for &ec in external_controls {
        fixed.push((ec, true));
    }
    fixed.sort_unstable_by_key(|&(p, _)| p);

    let n_qubits = len.trailing_zeros();
    let outer_count = 1usize << (n_qubits as usize - fixed.len());

    for k in 0..outer_count {
        let outer = crate::kernels::expand_with_fixed(k, &fixed);
        // The base `outer` has both lo and hi bits = 1.  Free positions
        // below lo span [0, lo); inner walk steps LANES amps through
        // those.  Wait — if `fixed` includes (lo, true), then free
        // positions below lo are still free, but `outer` will have
        // bit lo = 1.  The amps at outer, outer+1, ..., outer+lo_bit-1
        // all have bit lo = 0... no, they have bit lo = 1 from the
        // base. Let me re-derive:
        //
        // expand_with_fixed places fixed bits at their absolute
        // positions; free bits from `k` fill the remaining positions
        // in low-to-high order.  So `outer`'s bit `lo` IS 1, regardless
        // of where free bits land.  For the inner SIMD walk to step
        // contiguous amps that all share (bit_lo=1, bit_hi=1) — and
        // the only bits we want to vary in the inner walk are those
        // strictly below `lo` (positions 0..lo) — we need `outer` to
        // already have all those low bits zero.
        //
        // expand_with_fixed gives us this iff none of the free positions
        // is below `lo`.  Since (lo, true) is in `fixed`, positions
        // 0..lo are NOT in `fixed`; they ARE free.  So expand_with_fixed
        // will fill them with bits from `k`.  That breaks the
        // contiguous inner walk assumption.
        //
        // Fix: explicitly use only the high-bit positions as free,
        // and walk the inner LANES-stride over bit pattern j ∈ [0, lo_bit).
        // Same idiom as apply_1q_avx512's controlled path (aos.rs:223-248):
        // renormalise control positions above target.
        //
        // Re-derivation: for CZ, the inner walk spans amps where
        // bits < lo vary freely.  Outer = (bits >= lo with hi=1, lo=1
        // and external_controls=1).  Free positions for `outer` are
        // those > lo that are NOT hi and NOT an external_control.
        // We need to renormalise: subtract `lo + 1` from each fixed
        // position so they index into the "above lo" space, expand,
        // then shift back left by `lo + 1`.
        let _ = outer;
        // discard the simple expansion; replace with renormalised version below
    }

    // Renormalised outer-walk (mirrors apply_1q_diagonal_avx512's
    // controlled path):
    let mut fixed_above: smallvec::SmallVec<[(u32, bool); 16]> = smallvec::SmallVec::new();
    fixed_above.push((hi - lo - 1, true));
    for &ec in external_controls {
        fixed_above.push((ec - lo - 1, true));
    }
    fixed_above.sort_unstable_by_key(|&(p, _)| p);

    let outer_count = 1usize
        << (n_qubits as usize - lo as usize - 1 - external_controls.len() - 1);
    for k in 0..outer_count {
        let base = crate::kernels::expand_with_fixed(k, &fixed_above) << (lo + 1);
        // base has bits 0..lo zero, bit lo zero (it's just been shifted),
        // bit hi = 1.  We need bit lo = 1 as well.
        let outer = base | lo_bit;

        let mut j = 0usize;
        while j + LANES <= lo_bit {
            let i = outer | j;
            // SAFETY: i + LANES ≤ outer + lo_bit ≤ len.
            let z = _mm512_loadu_pd(amps_ptr.add(i * 2));
            let z = _mm512_xor_pd(z, sign_mask);
            _mm512_storeu_pd(amps_ptr.add(i * 2), z);
            j += LANES;
        }
        debug_assert_eq!(j, lo_bit);
    }
}
```

**Note:** the `outer_count` calculation above assumes `lo > 0`. If `lo == 0`, the renormalised path divides by `lo_bit = 1` and degenerates; but Tier A requires `lo_bit >= 4`, so `lo >= 2`. Safe.

```rust
/// Packed AVX-512 2q-diagonal (Tier A — `1 << min(targets) >= LANES`).
/// Walks four sub-blocks per outer step, each applying a single
/// constant complex multiply via the P1-06 1q-diagonal idiom.
///
/// # Safety
///
/// * AVX-512F supported.
/// * `1 << min(targets) >= LANES` (= 4).
/// * External controls > max(targets).
#[cfg(target_arch = "x86_64")]
#[target_feature(enable = "avx512f")]
unsafe fn apply_2q_diagonal_avx512(
    amps: &mut [Complex],
    targets: [u32; 2],
    external_controls: &[u32],
    d: [Complex; 4],
) {
    use core::arch::x86_64::*;

    const LANES: usize = 4;
    let lo = targets[0].min(targets[1]);
    let hi = targets[0].max(targets[1]);
    let lo_bit = 1usize << lo;
    let hi_bit = 1usize << hi;
    let len = amps.len();

    debug_assert!(lo_bit >= LANES);
    debug_assert!(external_controls.iter().all(|&c| c > hi));

    // Determine which (lo, hi) bit-pair maps to each matrix-index k.
    // k bit 1 (MSB) is targets[0]; k bit 0 (LSB) is targets[1].
    // We need d[k] for each (hi_bit_value, lo_bit_value).
    let (d_for_hi0_lo0, d_for_hi0_lo1, d_for_hi1_lo0, d_for_hi1_lo1) =
        if targets[0] < targets[1] {
            // targets[0] = lo, targets[1] = hi
            // k=0: targets[0]=0, targets[1]=0 → (hi=0, lo=0)
            // k=1: targets[0]=0, targets[1]=1 → (hi=1, lo=0)
            // k=2: targets[0]=1, targets[1]=0 → (hi=0, lo=1)
            // k=3: targets[0]=1, targets[1]=1 → (hi=1, lo=1)
            (d[0], d[2], d[1], d[3])
        } else {
            // targets[0] = hi, targets[1] = lo
            // k=0: (hi=0, lo=0)
            // k=1: targets[0]=0, targets[1]=1 → (hi=0, lo=1)
            // k=2: targets[0]=1, targets[1]=0 → (hi=1, lo=0)
            // k=3: (hi=1, lo=1)
            (d[0], d[1], d[2], d[3])
        };

    let bcast = |c: Complex| (_mm512_set1_pd(c.re), _mm512_set1_pd(c.im));
    let (d00r, d00i) = bcast(d_for_hi0_lo0);
    let (d01r, d01i) = bcast(d_for_hi0_lo1);
    let (d10r, d10i) = bcast(d_for_hi1_lo0);
    let (d11r, d11i) = bcast(d_for_hi1_lo1);

    let amps_ptr = amps.as_mut_ptr() as *mut f64;

    let multiply_block = |base: usize, d_re: __m512d, d_im: __m512d| {
        let mut j = 0usize;
        while j + LANES <= lo_bit {
            let i = base | j;
            let z = _mm512_loadu_pd(amps_ptr.add(i * 2));
            let zs = _mm512_permute_pd::<0x55>(z);
            let t = _mm512_mul_pd(d_im, zs);
            let out = _mm512_fmaddsub_pd(d_re, z, t);
            _mm512_storeu_pd(amps_ptr.add(i * 2), out);
            j += LANES;
        }
        debug_assert_eq!(j, lo_bit);
    };

    // Outer-walk: hi and lo bits both free; external_controls = 1.
    let mut fixed_above: smallvec::SmallVec<[(u32, bool); 16]> = smallvec::SmallVec::new();
    for &ec in external_controls {
        fixed_above.push((ec - lo - 1, true));
    }
    fixed_above.sort_unstable_by_key(|&(p, _)| p);

    // Note: hi is "above lo" but it's a target, not a control; we
    // iterate hi explicitly inside the loop.
    let n_qubits = len.trailing_zeros();
    let outer_count = 1usize
        << (n_qubits as usize - lo as usize - 1 - external_controls.len() - 1);
    // The "-1" accounts for the hi qubit, which we iterate via the
    // hi=0 and hi=1 cases below.

    for k in 0..outer_count {
        // base_renorm has bits 0..lo zero, bit (hi - lo - 1) zero
        // (we'll OR in hi explicitly), and external_controls fixed.
        let mut fixed_full = fixed_above.clone();
        fixed_full.push((hi - lo - 1, false));
        fixed_full.sort_unstable_by_key(|&(p, _)| p);
        let base_renorm = crate::kernels::expand_with_fixed(k, &fixed_full);
        let base = base_renorm << (lo + 1);

        // hi=0, lo=0
        multiply_block(base, d00r, d00i);
        // hi=0, lo=1
        multiply_block(base | lo_bit, d01r, d01i);
        // hi=1, lo=0
        multiply_block(base | hi_bit, d10r, d10i);
        // hi=1, lo=1
        multiply_block(base | hi_bit | lo_bit, d11r, d11i);
```

```rust
pub(crate) fn apply_2q_cnot_scalar(
    re: &mut [f64],
    im: &mut [f64],
    control: u32,
    target: u32,
    external_controls: &[u32],
) {
    debug_assert_eq!(re.len(), im.len());

    let t_bit = 1usize << target;
    let ctrl_mask = c_bit | super::control_mask(external_controls);

            im.swap(i, i | t_bit);
        }
        i += 1;
    }

    re: &mut [f64],
    im: &mut [f64],
    targets: [u32; 2],
    external_controls: &[u32],
) {
    debug_assert_eq!(re.len(), im.len());

    let b_bit = 1usize << targets[1];

    let ctrl_mask = super::control_mask(external_controls);
    let len = re.len();

            im.swap(i | a_bit, i | b_bit);

pub(crate) fn apply_2q_cz_scalar(
    re: &mut [f64],
    im: &mut [f64],
    targets: [u32; 2],
    external_controls: &[u32],
) {
    debug_assert_eq!(re.len(), im.len());
    let t0_bit = 1usize << targets[0];
    let t1_bit = 1usize << targets[1];
    let t_mask = t0_bit | t1_bit;
    let ctrl_mask = super::control_mask(external_controls);
    let len = re.len();
    let mut i = 0usize;
    while i < len {
        if (i & t_mask) == t_mask && (i & ctrl_mask) == ctrl_mask {

            im[i] = -im[i];
        }
        i += 1;

/// SoA scalar 2q-diagonal specialisation.
pub(crate) fn apply_2q_diagonal_scalar(
    re: &mut [f64],
    im: &mut [f64],
    targets: [u32; 2],
    external_controls: &[u32],
    d: [Complex; 4],
) {
    debug_assert_eq!(re.len(), im.len());
    let t0_bit = 1usize << targets[0];
    let t1_bit = 1usize << targets[1];
    let ctrl_mask = super::control_mask(external_controls);
    let len = re.len();
    let mut i = 0usize;
    while i < len {
        if (i & ctrl_mask) == ctrl_mask {
            let k_hi = ((i & t0_bit) != 0) as usize;
            let k_lo = ((i & t1_bit) != 0) as usize;
            let k = (k_hi << 1) | k_lo;
            let r = re[i];
            let im_v = im[i];
            re[i] = r * d[k].re - im_v * d[k].im;
            im[i] = r * d[k].im + im_v * d[k].re;
        }
        i += 1;
    }
}
```

```rust
const LANES_SOA: usize = 8;

/// SoA AVX-512 CNOT (Tier A — `1 << target >= LANES_SOA`).
///
/// # Safety
///
/// * AVX-512F supported.
/// * `1 << target >= 8`.
/// * Distinct `control != target` in qubit range.
/// * External controls > max(control, target).
#[cfg(target_arch = "x86_64")]
#[target_feature(enable = "avx512f")]
unsafe fn apply_2q_cnot_avx512(
    re: &mut [f64],
    im: &mut [f64],
    control: u32,
    target: u32,
    external_controls: &[u32],
) {
    use core::arch::x86_64::*;
    let t_bit = 1usize << target;
    let len = re.len();
    debug_assert!(t_bit >= LANES_SOA);

    let re_ptr = re.as_mut_ptr();
    let im_ptr = im.as_mut_ptr();

    let mut fixed: smallvec::SmallVec<[(u32, bool); 16]> = smallvec::SmallVec::new();
    fixed.push((target, false));
    fixed.push((control, true));
    for &ec in external_controls { fixed.push((ec, true)); }
    fixed.sort_unstable_by_key(|&(p, _)| p);

    let n_qubits = len.trailing_zeros();
    let outer_count = 1usize << (n_qubits as usize - fixed.len());

    for k in 0..outer_count {
        let outer = crate::kernels::expand_with_fixed(k, &fixed);
        let mut j = 0usize;
        while j + LANES_SOA <= t_bit {
            let i0 = outer | j;
            let i1 = i0 | t_bit;
            let ar = _mm512_loadu_pd(re_ptr.add(i0));
            let br = _mm512_loadu_pd(re_ptr.add(i1));
            let ai = _mm512_loadu_pd(im_ptr.add(i0));
            let bi = _mm512_loadu_pd(im_ptr.add(i1));
            _mm512_storeu_pd(re_ptr.add(i0), br);
            _mm512_storeu_pd(re_ptr.add(i1), ar);
            _mm512_storeu_pd(im_ptr.add(i0), bi);
            _mm512_storeu_pd(im_ptr.add(i1), ai);
            j += LANES_SOA;
        }
        debug_assert_eq!(j, t_bit);
    }
}

/// SoA AVX-512 CZ (Tier A — `vxorpd` sign-flip on both streams).

    im: &mut [f64],
    targets: [u32; 2],
    external_controls: &[u32],

    let lo = targets[0].min(targets[1]);
    let hi = targets[0].max(targets[1]);
    let lo_bit = 1usize << lo;
    let len = re.len();
    debug_assert!(lo_bit >= LANES_SOA);

    let re_ptr = re.as_mut_ptr();
    let im_ptr = im.as_mut_ptr();

    for k in 0..outer_count {
        let base = crate::kernels::expand_with_fixed(k, &fixed_above) << (lo + 1);
        let outer = base | lo_bit;
        let mut j = 0usize;
        while j + LANES_SOA <= lo_bit {
            let i = outer | j;
            let r = _mm512_loadu_pd(re_ptr.add(i));
            let imv = _mm512_loadu_pd(im_ptr.add(i));
            _mm512_storeu_pd(re_ptr.add(i), _mm512_xor_pd(r, sign_mask));
            _mm512_storeu_pd(im_ptr.add(i), _mm512_xor_pd(imv, sign_mask));
            j += LANES_SOA;
        }
        debug_assert_eq!(j, lo_bit);
    }
}

/// SoA AVX-512 2q-diagonal (Tier A).  Cross-multiply per-stream:
/// new_re = re * d_re - im * d_im; new_im = re * d_im + im * d_re.
#[cfg(target_arch = "x86_64")]
#[target_feature(enable = "avx512f")]
unsafe fn apply_2q_diagonal_avx512(
    re: &mut [f64],
    im: &mut [f64],
    targets: [u32; 2],
    external_controls: &[u32],
    d: [Complex; 4],
) {
    use core::arch::x86_64::*;
    let lo = targets[0].min(targets[1]);
    let hi = targets[0].max(targets[1]);
    let lo_bit = 1usize << lo;
    let hi_bit = 1usize << hi;
    let len = re.len();
    debug_assert!(lo_bit >= LANES_SOA);

    let (d_for_hi0_lo0, d_for_hi0_lo1, d_for_hi1_lo0, d_for_hi1_lo1) =
        if targets[0] < targets[1] {
            (d[0], d[2], d[1], d[3])
        } else {
            (d[0], d[1], d[2], d[3])
        };

    let re_ptr = re.as_mut_ptr();
    let im_ptr = im.as_mut_ptr();

    let multiply_block = |base: usize, dx: Complex| {
        let d_re_bc = _mm512_set1_pd(dx.re);
        let d_im_bc = _mm512_set1_pd(dx.im);
        let mut j = 0usize;
        while j + LANES_SOA <= lo_bit {
            let i = base | j;
            let r = _mm512_loadu_pd(re_ptr.add(i));
            let imv = _mm512_loadu_pd(im_ptr.add(i));
            // new_re = r * d_re - imv * d_im
            let new_r = _mm512_fnmadd_pd(imv, d_im_bc, _mm512_mul_pd(r, d_re_bc));
            // new_im = r * d_im + imv * d_re
            let new_i = _mm512_fmadd_pd(r, d_im_bc, _mm512_mul_pd(imv, d_re_bc));
            _mm512_storeu_pd(re_ptr.add(i), new_r);
            _mm512_storeu_pd(im_ptr.add(i), new_i);
            j += LANES_SOA;
        }
        debug_assert_eq!(j, lo_bit);
    };

    let mut fixed_above: smallvec::SmallVec<[(u32, bool); 16]> = smallvec::SmallVec::new();
    for &ec in external_controls { fixed_above.push((ec - lo - 1, true)); }
    fixed_above.sort_unstable_by_key(|&(p, _)| p);

    let n_qubits = len.trailing_zeros();
    let outer_count = 1usize << (n_qubits as usize - lo as usize - 1 - external_controls.len() - 1);

    for k in 0..outer_count {
        let mut fixed_full = fixed_above.clone();
        fixed_full.push((hi - lo - 1, false));
        fixed_full.sort_unstable_by_key(|&(p, _)| p);
        let base = crate::kernels::expand_with_fixed(k, &fixed_full) << (lo + 1);
        multiply_block(base, d_for_hi0_lo0);
        multiply_block(base | lo_bit, d_for_hi0_lo1);
        multiply_block(base | hi_bit, d_for_hi1_lo0);
        multiply_block(base | hi_bit | lo_bit, d_for_hi1_lo1);
    }
}
```

```rust
//! 1. `cnot_specialized` vs `cnot_via_generic` — pins BACKLOG-AC claim
//!    "CNOT ≥ 5× faster than generic 2q kernel".  `via_generic` forces

//!    `GenericUnitary` matrix that escapes `classify_2q_permutation`

//!    special dense 2q matrix.  Must be < 2 % of `apply_2q_dense_scalar`
//!    wall-clock.

use aleph_core::{Complex, Gate};
use aleph_ir::{Circuit, OpKind};
use aleph_sv::{Backend, NaiveSvBackend};
use criterion::{black_box, criterion_group, criterion_main, Criterion};
use smallvec::smallvec;

fn build_cnot_circuit(n: u32, gates: usize) -> Circuit {
    let mut circ = Circuit::new(n);
    for k in 0..gates {
        let c = (k as u32) % n;
        let t = ((k as u32) + 1) % n;
        if c == t { continue; }
        circ.push(OpKind::Gate {
            gate: Gate::Cnot,
            qubits: smallvec![c, t],
            controls: smallvec![],
        }).unwrap();
    }
    circ
}

fn build_cnot_via_generic_circuit(n: u32, gates: usize) -> Circuit {
    // Build a CNOT matrix with a 1e-12 off-diagonal perturbation so
    // classify_2q_permutation fails and the generic path is taken.
    let mut m = [[Complex::new(0.0, 0.0); 4]; 4];
    m[0][0] = Complex::new(1.0, 0.0);
    m[1][1] = Complex::new(1.0, 0.0);
    m[2][3] = Complex::new(1.0, 0.0);
    m[3][2] = Complex::new(1.0, 0.0);
    m[0][1] = Complex::new(1e-12, 0.0); // breaks permutation detection
    let mut circ = Circuit::new(n);
    for k in 0..gates {
        let c = (k as u32) % n;
        let t = ((k as u32) + 1) % n;
        if c == t { continue; }
        circ.push(OpKind::Gate {
            gate: Gate::GenericUnitary2q(Box::new(m)),
            qubits: smallvec![c, t],
            controls: smallvec![],
        }).unwrap();
    }
    circ
}

fn build_dense_2q_circuit(n: u32, gates: usize) -> Circuit {
    // Random dense 2q (not diagonal, not permutation).
    let mut m = [[Complex::new(0.0, 0.0); 4]; 4];
    let mut s: u64 = 1;
    let mut lcg = || {
        s = s.wrapping_mul(6364136223846793005).wrapping_add(1442695040888963407);
        ((s >> 32) as f64 / (u32::MAX as f64)) * 2.0 - 1.0
    };
    for r in 0..4 {
        for c in 0..4 {
            m[r][c] = Complex::new(lcg(), lcg());
        }
    }
    let mut circ = Circuit::new(n);
    for k in 0..gates {
        let c = (k as u32) % n;
        let t = ((k as u32) + 1) % n;
        if c == t { continue; }
        circ.push(OpKind::Gate {
            gate: Gate::GenericUnitary2q(Box::new(m)),
            qubits: smallvec![c, t],
            controls: smallvec![],
        }).unwrap();
    }
    circ
}
```

```bash
## Context

Phase 1 Stage 0 baseline (`docs/perf/phase1-vs-qiskit.md`) confirmed
QFT-20 is the only Tier-1 workload over the ROADMAP ≤ 2× Aer target,
with 39 % of its transpiled gates being scalar-`apply_2q` CNOTs.  P1-06's

## Decision

`apply_2q` dispatch is matrix-based (extends ADR 0009): runtime
`classify_2q_permutation` + `is_diagonal_4x4` + `is_cz_signature`
detection routes to one of six paths:

1. Identity — no-op return.
2. CNOT (CnotHi / CnotLo) — swap-pair, 3 SIMD tiers + scalar.
3. SWAP — swap-pair, 3 SIMD tiers + scalar.
4. CZ — `vxorpd` sign-flip, Tier A SIMD + scalar.
5. 2q-diagonal — single-stream multiply, Tier A SIMD + scalar.
6. Generic dense 4×4 — packed-complex AVX-512 (Tier A) + scalar.

## Three-tier SIMD coverage

* Tier A: `1 << min(targets) ≥ LANES`.  Classic LANES-aligned block-walk.
* Tier B: `1 << min(targets) < LANES ≤ 1 << max(targets)`.  In-register
  `vpermt2pd` / `vpermutexvar_pd` per zmm-load.
* Tier C: both qubits in {0, 1}.  One quartet per zmm, single permute.

Tiers B and C apply only to CNOT and SWAP — CZ and diagonal have small
1/4 / per-bitpattern footprints where scalar fallback is plenty fast.

## Performance shape (EPYC, n=20, post-P1-06 baseline 1133 ms)

* CNOT/SWAP specialised: ~16× per-amp vs scalar generic-2q matmul; touches
  only half the state (CNOT) or 1/2 + 1/2 swap pairs (SWAP).
* CZ specialised: 0.75 µops per amp + 4× bandwidth reduction (touches
  1/4).
* 2q-diagonal: 1.25 µops per amp vs ~3.5 for generic SIMD (~2.8× per-amp).
* Generic dense SIMD: ~4.5× per-amp vs scalar.
```
