# [P2-07] Deep k-qubit Gate Fusion Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add `FuseKq`, an IR pass that greedily fuses adjacent gates spanning ≤ `max_qubits` (≤5) qubits into a single dense `2^k × 2^k` `Gate::UnitaryKq`, applied in one state-vector pass by a scalar + AVX-512 generic-`k` kernel — raising arithmetic intensity for VQE/QAOA/random workloads.

**Architecture:** A complementary pass running **after** `Fuse1q`/`Fuse2q`/`FuseDiagonal`, merging the dense 1q/2q blocks they produced into 3–5q dense blocks (cost model: only fuse a block spanning ≥3 qubits that absorbs ≥2 gates). A new `Gate::UnitaryKq{k,data}` carries the flattened `2^k×2^k` matrix; the backend dispatches it to `apply_kq`, which generalizes P1-07's renormalised outer-walk to arbitrary `k`.

**Tech Stack:** Rust 2021, `rayon`, AVX-512 intrinsics, `criterion`, `proptest`.

**Reference spec:** `docs/superpowers/specs/2026-06-03-p2-07-fuse-kq-design.md`.

**Golden-rule reminders:**

- No `unwrap()`/`expect()` in library code (tests OK); `?` with `thiserror`.
- No `unsafe` without a `// SAFETY:` block. ## Task 2: `lift_to_block` — embed a gate matrix into the k-qubit block space

**Files:** Create `crates/aleph-ir/src/passes/fuse_kq.rs`; modify `crates/aleph-ir/src/passes/mod.rs` (add `pub mod fuse_kq;` only).

**Background:** A block spans sorted qubits `Q = [q0<q1<…<q_{k-1}]`. A member gate
acts on a subset `gq ⊆ Q` with its own operand order. To compose members into one
`2^k×2^k` matrix, each member's matrix must be lifted to the block space: tensored
with identity on `Q∖gq` and permuted so the member's operands map to the right
block-bit positions. Block-bit position `p` (0=LSB … k-1=MSB) corresponds to
qubit `Q[k-1-p]` (MSB-first: `Q[0]` is the highest block bit). A member operand
`gq[a]` (its matrix MSB-first bit `arity-1-a`) maps to block bit position
`p` where `Q[k-1-p] == gq[a]`.

- [ ] **Step 1: Write the failing tests** (in `fuse_kq.rs`, `mod lift_tests`):

//! `FuseKq` — greedy fusion of adjacent gates into dense k-qubit blocks.
//! See docs/superpowers/specs/2026-06-03-p2-07-fuse-kq-design.md.

use aleph_core::Complex;

#[cfg(test)]
mod lift_tests {
    use super::*;
    use aleph_core::{Gate, GateInstance};
    use smallvec::smallvec;

    // Brute-force reference: apply `gate` (on `gate_qubits`) to each block
    // basis state |x⟩ (x over the k block qubits in MSB-first order Q) and
    // read off the lifted column.
    fn brute_lift(gate: &Gate, gate_qubits: &[u32], block_qubits: &[u32]) -> Vec<Complex> {
        let k = block_qubits.len();
        let dim = 1usize << k;
        let gm = gate.matrix().unwrap();
        let gd = match gm {
            aleph_core::GateMatrix::M2x2(m) => m.iter().flatten().copied().collect::<Vec<_>>(),
            aleph_core::GateMatrix::M4x4(m) => m.iter().flatten().copied().collect::<Vec<_>>(),
            aleph_core::GateMatrix::M8x8(m) => m.iter().flatten().copied().collect::<Vec<_>>(),
        };
        let ga = gate_qubits.len();
        let gdim = 1usize << ga;
        // block bit p (0=LSB) ↔ qubit block_qubits[k-1-p]
        let block_bit_of = |q: u32| -> usize {
            let idx = block_qubits.iter().position(|&bq| bq == q).unwrap();
            k - 1 - idx
        };
        // gate matrix bit p (0=LSB) ↔ gate_qubits[ga-1-p]
        let mut out = vec![Complex::new(0.0, 0.0); dim * dim];
        for col in 0..dim {
            // extract the gate-operand input pattern from col
            let mut gin = 0usize;
            for a in 0..ga {
                let bb = block_bit_of(gate_qubits[a]); // block bit for this operand
                let bit = (col >> bb) & 1;
                // operand a is gate matrix bit (ga-1-a)
                gin |= bit << (ga - 1 - a);
            }
            for grow in 0..gdim {
                let amp = gd[grow * gdim + gin];
                if amp.norm() < 1e-18 { continue; }
                // build output row = col with the gate operand bits replaced by grow
                let mut row = col;
                for a in 0..ga {
                    let bb = block_bit_of(gate_qubits[a]);
                    let outbit = (grow >> (ga - 1 - a)) & 1;
                    row = (row & !(1 << bb)) | (outbit << bb);
                }
                out[row * dim + col] += amp;
            }
        }
        out
    }

    #[test]

use aleph_core::{Gate, GateMatrix};

/// Embed a gate's matrix into the `k`-qubit block space spanned by sorted
/// `block_qubits` (ascending). `gate_qubits` is the gate's own operand list
/// (its matrix MSB-first: `gate_qubits[0]` is the gate-matrix MSB). Returns
/// the row-major `2^k × 2^k` lifted matrix. The gate must be a fixed-size
/// gate whose `matrix()` returns `M2x2/M4x4/M8x8` (arity ≤ 3); a `UnitaryKq`
/// member is lifted by `lift_dense` (Task 3) instead.
pub(crate) fn lift_to_block(gate: &Gate, gate_qubits: &[u32], block_qubits: &[u32]) -> Vec<Complex> {
    let gd = match gate.matrix().expect("liftable member must have a GateMatrix") {
        GateMatrix::M2x2(m) => m.iter().flatten().copied().collect::<Vec<_>>(),
        GateMatrix::M4x4(m) => m.iter().flatten().copied().collect::<Vec<_>>(),
        GateMatrix::M8x8(m) => m.iter().flatten().copied().collect::<Vec<_>>(),
    };
    lift_dense(&gd, gate_qubits, block_qubits)
}

/// As `lift_to_block` but for an already-flattened dense `2^ga × 2^ga` matrix
/// (`ga == gate_qubits.len()`). Shared by standard gates and nested `UnitaryKq`.
pub(crate) fn lift_dense(gd: &[Complex], gate_qubits: &[u32], block_qubits: &[u32]) -> Vec<Complex> {
    let k = block_qubits.len();
    let dim = 1usize << k;
    let ga = gate_qubits.len();
    let gdim = 1usize << ga;
    debug_assert_eq!(gd.len(), gdim * gdim);
    // block bit position p (0=LSB) for a qubit ↔ block_qubits[k-1-p]
    let block_bit_of = |q: u32| -> usize {
        let idx = block_qubits.iter().position(|&bq| bq == q)
            .expect("gate qubit must lie in block");
        k - 1 - idx
    };
    let mut out = vec![Complex::new(0.0, 0.0); dim * dim];
    for col in 0..dim {
        let mut gin = 0usize;
        for a in 0..ga {
            let bb = block_bit_of(gate_qubits[a]);
            gin |= ((col >> bb) & 1) << (ga - 1 - a);
        }
        for grow in 0..gdim {
            let amp = gd[grow * gdim + gin];
            if amp == Complex::new(0.0, 0.0) { continue; }
            let mut row = col;
            for a in 0..ga {
                let bb = block_bit_of(gate_qubits[a]);
                let outbit = (grow >> (ga - 1 - a)) & 1;
                row = (row & !(1usize << bb)) | (outbit << bb);
            }
            out[row * dim + col] += amp;
        }
    }
    out
}
```

use aleph_core::GateInstance;

/// Compose member gates (circuit order) into one row-major `2^k×2^k` matrix
/// over the sorted `block_qubits`. Members must each act within `block_qubits`
/// and have arity ≤ 3 (or be a `UnitaryKq` — handled via its `data`).
pub(crate) fn build_block_matrix(members: &[GateInstance], block_qubits: &[u32]) -> Vec<Complex> {
    let k = block_qubits.len();
    let dim = 1usize << k;
    // identity
    let mut acc = vec![Complex::new(0.0, 0.0); dim * dim];
    for i in 0..dim { acc[i * dim + i] = Complex::new(1.0, 0.0); }
    for gi in members {
        let lifted = match &gi.gate {
            Gate::UnitaryKq { data, .. } => lift_dense(data, &gi.qubits, block_qubits),
            _ => lift_to_block(&gi.gate, &gi.qubits, block_qubits),
        };
        acc = matmul(&lifted, &acc, dim); // acc := lifted · acc
    }
    acc
}

/// Row-major dense `n×n` product `a · b`.
fn matmul(a: &[Complex], b: &[Complex], n: usize) -> Vec<Complex> {
    let mut out = vec![Complex::new(0.0, 0.0); n * n];
    for i in 0..n {
        for k in 0..n {
            let aik = a[i * n + k];
            if aik == Complex::new(0.0, 0.0) { continue; }
            for j in 0..n {
                out[i * n + j] += aik * b[k * n + j];
            }
        }
    }
    out
}
```

use crate::passes::{Pass, PassError, PassStats};
use crate::{Circuit, Instruction};

/// Fuses adjacent gates spanning ≤ `max_qubits` into a dense `UnitaryKq`,
/// running after Fuse1q/Fuse2q/FuseDiagonal. Greedy, dependency-respecting.
pub struct FuseKq { pub max_qubits: usize }

impl Default for FuseKq {
    fn default() -> Self { Self { max_qubits: 4 } } // tuned on EPYC in the perf task
}

struct Block { qubits: Vec<u32>, members: Vec<GateInstance>, first_idx: usize }

impl Pass for FuseKq {
    fn name(&self) -> &'static str { "FuseKq" }

    fn run(&self, circuit: &mut Circuit) -> Result<PassStats, PassError> {
        let n = circuit.num_qubits();
        let before = circuit.len();
        let max_k = self.max_qubits.clamp(2, 5);
        let input = circuit.instructions.clone();

        // Open blocks, and per-qubit which open-block index owns it.
        let mut blocks: Vec<Option<Block>> = Vec::new();
        let mut owner: Vec<Option<usize>> = vec![None; n as usize];
        // Output accumulator with a sort key (min member idx) for stable order.
        let mut out: Vec<(usize, Instruction)> = Vec::new();
        let mut transformations = 0u64;

        // Close a block: emit dense if cost model passes, else re-emit members.
        // Pushes onto `out` keyed by first_idx.
        fn close(b: Block, out: &mut Vec<(usize, Instruction)>, transformations: &mut u64) {
            let span = b.qubits.len();
            if span >= 3 && b.members.len() >= 2 {
                let mut q = b.qubits.clone();
                q.sort_unstable();
                let data = build_block_matrix(&b.members, &q);
                let g = aleph_core::GateInstance::new(
                    aleph_core::Gate::UnitaryKq { k: span as u8, data: data.into_boxed_slice() },
                    q.into(),
                );
                out.push((b.first_idx, Instruction::Gate(g)));
                *transformations += 1;
            } else {
                for (off, m) in b.members.into_iter().enumerate() {
                    out.push((b.first_idx + off, Instruction::Gate(m)));
                }
            }
        }

        let close_blocks_touching = |qs: &[u32],
                                     blocks: &mut Vec<Option<Block>>,
                                     owner: &mut Vec<Option<usize>>,
                                     out: &mut Vec<(usize, Instruction)>,
                                     transformations: &mut u64| {
            let mut to_close = std::collections::BTreeSet::new();
            for &q in qs {
                if let Some(bi) = owner[q as usize] { to_close.insert(bi); }
            }
            for bi in to_close {
                if let Some(b) = blocks[bi].take() {
                    for &q in &b.qubits { owner[q as usize] = None; }
                    close(b, out, transformations);
                }
            }
        };

        for (idx, inst) in input.iter().enumerate() {
            match inst {
                Instruction::Gate(g) if !matches!(g.gate, aleph_core::Gate::UnitaryKq{..}) => {
                    let s = g.qubits.clone(); // standard gates have no external controls post-fusion;
                    // if controls present, treat the whole support as the block span:
                    let mut support: Vec<u32> = g.used_qubits().to_vec();
                    support.sort_unstable();
                    // Gather dependency blocks.
                    let mut dep: std::collections::BTreeSet<usize> = std::collections::BTreeSet::new();
                    for &q in &support {
                        if let Some(bi) = owner[q as usize] { dep.insert(bi); }
                    }
                    // Candidate merged span.
                    let mut merged: std::collections::BTreeSet<u32> = support.iter().copied().collect();
                    for &bi in &dep {
                        if let Some(b) = &blocks[bi] { merged.extend(b.qubits.iter().copied()); }
                    }
                    if merged.len() <= max_k {
                        // Merge all dep blocks + this gate into one new block.
                        let mut members = Vec::new();
                        let mut first_idx = idx;
                        // collect in first_idx order
                        let mut deps_sorted: Vec<usize> = dep.iter().copied().collect();
                        deps_sorted.sort_by_key(|&bi| blocks[bi].as_ref().map(|b| b.first_idx).unwrap_or(usize::MAX));
                        for bi in deps_sorted {
                            if let Some(b) = blocks[bi].take() {
                                first_idx = first_idx.min(b.first_idx);
                                members.extend(b.members);
                            }
                        }
                        members.push(g.clone());
                        let qubits: Vec<u32> = merged.into_iter().collect();
                        let new_bi = blocks.len();
                        for &q in &qubits { owner[q as usize] = Some(new_bi); }
                        blocks.push(Some(Block { qubits, members, first_idx }));
                    } else {
                        // Close deps, then start fresh single-gate block.
                        let dep_qs: Vec<u32> = dep.iter()
                            .filter_map(|&bi| blocks[bi].as_ref())
                            .flat_map(|b| b.qubits.iter().copied())
                            .collect();
                        close_blocks_touching(&dep_qs, &mut blocks, &mut owner, &mut out, &mut transformations);
                        let qubits = support.clone();
                        let new_bi = blocks.len();
                        for &q in &qubits { owner[q as usize] = Some(new_bi); }
                        blocks.push(Some(Block { qubits, members: vec![g.clone()], first_idx: idx }));
                    }
                    let _ = s;
                }
                // UnitaryKq, DiagonalPhase, Measure, Reset, Barrier, or any gate
                // with controls we choose not to fuse: FENCE on touched qubits,
                // then emit verbatim.
                other => {
                    let qs: Vec<u32> = other.used_qubits().to_vec();
                    close_blocks_touching(&qs, &mut blocks, &mut owner, &mut out, &mut transformations);
                    out.push((idx, other.clone()));
                }
            }
        }
        // Close any remaining open blocks.
        let remaining: Vec<usize> = (0..blocks.len()).collect();
        for bi in remaining {
            if let Some(b) = blocks[bi].take() {
                for &q in &b.qubits { owner[q as usize] = None; }
                close(b, &mut out, &mut transformations);
            }
        }

        out.sort_by_key(|(idx, _)| *idx);
        let result: Vec<Instruction> = out.into_iter().map(|(_, i)| i).collect();
        let after = result.len();
        circuit.instructions = result;
        Ok(PassStats { gates_before: before, gates_after: after, transformations })
    }
}

use crate::kernels::{par_blocks, BlockPtr, ComplexPtr};

fn sorted_targets_and_offsets(qubits: &[u32], k: u8) -> (Vec<u32>, Vec<usize>, Vec<(u32, bool)>) {
    let k = k as usize;
    let mut q = qubits.to_vec();
    q.sort_unstable();
    let offsets: Vec<usize> = (0..(1usize << k)).map(|m| {
        let mut off = 0usize;
        for p in 0..k {
            if (m >> p) & 1 == 1 { off |= 1usize << q[k - 1 - p]; }
        }
        off
    }).collect();
    let fixed: Vec<(u32, bool)> = q.iter().map(|&x| (x, false)).collect();
    (q, offsets, fixed)
}

pub(crate) fn apply_kq_scalar_aos(amps: &mut [Complex], qubits: &[u32], k: u8, data: &[Complex]) {
    let dim = 1usize << k;
    let (_q, offsets, fixed) = sorted_targets_and_offsets(qubits, k);
    let len = amps.len();
    let outer = len >> k as usize; // 2^(n-k)
    let p = ComplexPtr(amps.as_mut_ptr());
    par_blocks(DEFAULT_POLICY, outer, len, |c| c, move |counter| {
        let base = crate::kernels::expand_with_fixed(counter, &fixed);
        // gather

        for m in 0..dim {
            // SAFETY: base|offsets[m] are distinct in-range indices (coverage test);
            // disjoint across counters (par_blocks), no aliasing.
            inb[m] = unsafe { *p.ptr().add(base | offsets[m]) };
        }
        for r in 0..dim {
            let mut acc = Complex::new(0.0, 0.0);
            for cc in 0..dim { acc += data[r * dim + cc] * inb[cc]; }
            unsafe { *p.ptr().add(base | offsets[r]) = acc; }
        }
    });
}

pub(crate) fn apply_kq_scalar_soa(re: &mut [f64], im: &mut [f64], qubits: &[u32], k: u8, data: &[Complex]) {
    let dim = 1usize << k;
    let (_q, offsets, fixed) = sorted_targets_and_offsets(qubits, k);
    let len = re.len();
    let outer = len >> k as usize;
    let rp = BlockPtr(re.as_mut_ptr());
    let ip = BlockPtr(im.as_mut_ptr());
    par_blocks(DEFAULT_POLICY, outer, len, |c| c, move |counter| {
        let base = crate::kernels::expand_with_fixed(counter, &fixed);
        let mut inr = vec![0.0f64; dim];
        let mut ini = vec![0.0f64; dim];
        for m in 0..dim {
            // SAFETY: as AoS; disjoint indices.
            inr[m] = unsafe { *rp.0.add(base | offsets[m]) };
            ini[m] = unsafe { *ip.0.add(base | offsets[m]) };
        }
        for r in 0..dim {
            let mut ar = 0.0f64; let mut ai = 0.0f64;
            for cc in 0..dim {
                let d = data[r * dim + cc];
                ar += d.re * inr[cc] - d.im * ini[cc];
                ai += d.re * ini[cc] + d.im * inr[cc];
            }
            unsafe {
                *rp.0.add(base | offsets[r]) = ar;
                *ip.0.add(base | offsets[r]) = ai;
            }
        }
    });

- [ ] **Step 2: Implement AVX-512** for the dense matvec. The vectorizable dimension is the **outer** `2^(n-k)` walk (process LANES=8 outer-counters per step), OR vectorize the inner matvec across the `2^k` gathered amplitudes. Recommended: **vectorize the outer walk** — process 8 independent blocks per step, each doing the same `2^k×2^k` matvec, since blocks are disjoint and the access pattern across 8 blocks is regular. For each of the `2^k` rows, broadcast `data[r*dim+cc]` and FMA across the 8 blocks' `inb[cc]` lanes. This keeps `data` in registers and amortizes it across 8 blocks. AoS needs de-interleave (reuse P2-06 permutes); SoA is natural. Gate on `is_x86_feature_detected!("avx512f")`. Guard `outer < 8 → scalar`.
