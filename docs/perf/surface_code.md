**Hard target (P3-08 design): surface-d11 ≤ 2× Stim — NOT met (achieved 7.66×).**
The rowsum work landed its share — a real 1.63× cycle speedup at d=11 — but did not
close the gap to ≤2×, because `rowsum` was never the majority of the cycle. A
`perf record` of the d=11 cycle *after* this change attributes time as:

```
70.9%  Tableau::cnot      (gate kernel — per-row scalar column bit-twiddle)
15.3%  Tableau::h         (gate kernel)
 5.3%  Tableau::measure   (contains rowsum)
 3.5%  Tableau::zero_row
 2.6%  Tableau::copy_row
```

The cycle is now **gate-bound (cnot+h ≈ 86%)**; the measurement/`rowsum` path is
~5–11%. Closing the remaining gap to Stim's bit-packed CHP requires word-parallelizing
the **gate** kernels (CNOT/H), which touch a single column across all rows
(strided/gather under the row-major layout) — explicitly out of P3-08's scope and a
heavier change than `rowsum`. Correctness is unchanged: bit-exact vs the preserved
scalar `rowsum` (proptest, scalar + AVX-512) and all Stim oracles pass at d=3..11.
